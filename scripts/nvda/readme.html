DbDo NVDA Add-on

This add-on lets DbDo handle its own keyboard chords directly instead of NVDA intercepting them for browse-mode or table-navigation commands. It does not add features to NVDA; it only steps out of DbDo's way for a specific set of chords inside the DbDo application.

What it covers

The add-on passes the following chord families straight through to DbDo when DbDo is the foreground application:

  • Virtual-cell navigation: Alt+Control + Home / End / arrows / PageUp / PageDown / NumPad5
  • Alt-letter command shortcuts: Alt+A, C, D, E, K, L, P, R, T, Y, Z (plus Alt+Shift+A, D, R)
  • Parent-child drill: Alt+RightArrow, Alt+LeftArrow, Alt+Home, Alt+End
  • Three search families: Control+F / Control+J / Control+F3 plus Shift variants, F3, Shift+F3
  • Marked-row navigation: Control+Home, Control+End, Control+UpArrow, Control+DownArrow
  • Bulk-mark span: Shift+Home, Shift+End, plus Alt+Shift variants
  • Say-X data-list chords: Shift+D, L, T, Y, F4

The coverage is identical to what the DbDo.jkm key map does for JAWS.

Without this add-on

NVDA intercepts the Alt+Control+arrow family for its own table-navigation commands. Inside DbDo's virtual-mode ListView this produces "Not in a table" or similar messages, and DbDo's own cell-navigation announcements never fire. Several Alt-letter and Shift-letter chords run unrelated default NVDA actions.

How to (re)install or uninstall

DbDo's installer ships this add-on at {app}\DbDo.nvda-addon and offers to install it as a Finish-page checkbox. To reinstall manually, double-click DbDo.nvda-addon — NVDA opens its add-on install dialog. To uninstall, use NVDA's Tools menu > Manage Add-ons.
