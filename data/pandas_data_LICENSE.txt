Sample data from the pandas project

titanic.csv and the air_quality_*.csv files in this folder are the sample data of the pandas Getting Started
tutorials (pandas 3.1.1, doc/data in https://github.com/pandas-dev/pandas). DbDo ships them so the same tasks
can be done in DbDo; Tutorial 8 and notes\DbDo_Pandas_Equivalents.md use them. The air quality data come from
OpenAQ, through the py-openaq package.

Provenance: pandas commit 3dcc6fbbbebc5e85dd3e83fe49b382ca7735cae1 (v3.1.1 docs). The SHA-256 of each file as
pandas publishes it is below; the copies here differ only in having Windows line endings and a UTF-8 mark,
as every Homer text file does.
